# ExplainFlow Privacy Policy

Effective date: 2026-08-21

ExplainFlow is an open-source, instruction-only Agent Skill / plugin. The ExplainFlow package itself does not operate a separate backend service, maintain user accounts, run advertising, sell personal data, or independently store conversation content.

## Data handling

ExplainFlow provides reusable instructions that run inside the host product in which the skill or plugin is installed. Any prompts, files, generated outputs, product telemetry, retention, model-improvement settings, or account data are handled by that host product according to its own privacy terms and settings.

## External services

The current ExplainFlow public beta does not require an external API, MCP server, database, OAuth connection, or third-party app. If a future release adds an external service, this policy will be updated before that capability is released.

## Open-source repository

The public source code and documentation are hosted on GitHub. Visiting or interacting with the repository is subject to GitHub's own terms and privacy practices.

## Contact

For privacy questions or issues, open an issue in the public repository:
