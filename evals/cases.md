1. `/mindmap photosynthesis`
   - Must produce a single-root hierarchy with short branches.

2. `/flowchart password reset`
   - Must show start, verification, decision/failure path, reset, completion.

3. `/architecture React frontend, FastAPI backend, PostgreSQL, Redis`
   - Must include only requested/necessary components and directional flow.

4. `/cheatsheet Git basics`
   - Must be dense, scannable, and organized by task.

5. `/comparison REST vs GraphQL`
   - Must use matched criteria and avoid unsupported absolutes.
