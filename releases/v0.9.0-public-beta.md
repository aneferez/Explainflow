# ExplainFlow 0.9.0 Public Beta

ExplainFlow is now available as a public open-source Agent Skill beta.

## Included

- 30 documented slash commands
- command routing and precedence rules
- format-specific quality checks
- sample prompts
- 45 behavioral evaluation cases
- static GitHub Actions validation
- release checklist and changelog
- MIT license

## Public beta purpose

This beta is intended for real-world installation and behavioral testing before the stable `v1.0.0` release.

## Known release limitation

The repository specification and static validation are complete, but the full 45-case behavioral suite has not yet been executed in a real Agent Skills runtime. This is the primary gate for `v1.0.0`.

## Suggested first tests

1. `/mindmap React state management`
2. `/flowchart Password reset`
3. `/architecture React frontend, FastAPI backend, PostgreSQL, Redis`
4. `/cheatsheet Git basics`
5. `/summary /flowchart OAuth login`
