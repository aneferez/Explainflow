# ExplainFlow Quality Checks

## Mind maps / concept maps
- One clear root topic.
- Branches are mutually understandable.
- No branch contains a full paragraph.

## Flowcharts / workflows / pipelines
- Start and end states are visible.
- Every transition has a clear direction.
- Decision points show alternatives when needed.

## Architecture diagrams
- Separate clients, services, data stores, external systems, and infrastructure when applicable.
- Label data/control flow.
- Avoid inventing components not supported by the request.

## Timelines / roadmaps
- Order is explicit.
- Milestones or phases use consistent granularity.
- Dates are not invented.

## Cheat sheets
- High information density.
- Definitions, syntax, formulas, or commands are grouped.
- Remove narrative filler.

## Quizzes / flashcards
- Questions test the supplied topic.
- Answers are accurate and concise.
- Avoid trick questions unless requested.
